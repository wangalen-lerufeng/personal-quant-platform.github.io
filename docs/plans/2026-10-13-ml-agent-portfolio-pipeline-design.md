# 机器学习与多 Agent 组合研究流水线设计

## 定位

该方案用于增强候选资产筛选、证据研究和纸面仓位优化，不是自动保证盈利的 AI 交易机器人。第一版以 A 股 ETF 为试点，所有实盘能力保持关闭。

## 四层架构

1. **初筛与稳健预测**：Qlib 管理时序数据与实验，LightGBM 建立基线，DoubleEnsemble提供抗噪集成预测。
2. **精研验真**：TradingAgents 风格的多角色 Agent 读取真实行情、公告、新闻和结构化财务数据，输出带证据的通过、观察或排除结论。
3. **仓位微调**：PPO 只能在基线仓位的 0.8–1.2 倍范围内调整，奖励扣除成本、换手、回撤和风险暴露惩罚。
4. **最终风控**：现有确定性风险引擎拥有最高优先级，任何模型都不能修改或绕过风险限制。

## 安全降级

- 初筛模型失效：不生成新候选。
- Agent 数据或证据不足：候选进入观察或排除，不进入仓位优化。
- PPO 异常或样本外退化：退回固定仓位或波动率目标基线。
- 数据陈旧、API异常、回撤或亏损超限：禁止新增仓位并触发纸面熔断。

## 研究与验证要求

- 所有标签和特征按决策时点截断，禁止未来数据。
- 使用滚动训练、时间序列交叉验证和独立样本外测试。
- 与等权、固定仓位、波动率定仓等简单基线比较。
- 回测包含手续费、滑点、流动性、涨跌停、停牌和成交限制。
- 记录数据、特征、模型、提示词、Agent、策略和风控版本。

## 实施边界

第一阶段仅完成数据适配、离线训练、事件回测和纸面仿真。任何真实交易接口必须等待至少 30 个真实仿真交易日、自动对账通过、安全复审通过及人工审批。
