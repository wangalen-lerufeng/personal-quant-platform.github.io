# 动态选股研究与 Web 操作指南

> 更新日期：2026-10-20<br>
> 适用项目：Personal Quant Platform<br>
> 安全状态：仅研究与纸面仿真，真实交易关闭

## 1. 这次修改主要解决什么问题

本次修改把“未来 5 日标签、月度样本、行业内排名、历史动态流动性股票池”接入了组合研究流水线，并在 Web 控制台增加了可直接操作的入口。

重点解决以下问题：

1. **静态股票池存在选择偏差**
   如果使用今天看到的“高流动性前 100 只”回测过去，等于提前知道哪些股票后来仍然活跃。现在改为在每个历史日期只使用当时及以前的成交额，动态选出当时的高流动性股票。

2. **1 日预测与实际持有周期不匹配**
   原模型主要预测未来 1 日收益。现在可以选择未来 1、5、10、20 日收益，默认推荐未来 5 日，使标签周期更接近中短周期选股。

3. **每日样本过密，换手和噪声偏高**
   新增月度调仓模式，只保留每个自然月最后一个实际交易日的截面，降低样本重叠和无意义换手。

4. **不同行业的分数不能直接公平比较**
   新增行业内排名。模型先在同一行业内部进行百分位排序，再形成候选池，减少模型只是在押注行业差异的情况。

5. **研究参数只能在后端使用，网页无法操作**
   新参数已加入“组合研究”页面。用户可以在 Web 界面选择预测周期、调仓频率、动态股票池和行业内排名，不需要手工修改程序。

6. **Qlib 原始因子表达式可能导致 LightGBM 报错**
   因子表达式含有 `$`、括号、逗号等特殊字符。模型输入列现在会转换为 `F0`、`F1` 等安全名称，避免 LightGBM 因特征名格式而中断。

## 3. 修改后的数据流

```text
沪深 300 历史成分与 OHLCV
        ↓
每个历史日期计算过去 20 日平均成交额
        ↓
过滤历史不足 250 日的股票，并动态选 Top 100
        ↓
只保留月末截面
        ↓
计算 Qlib Alpha158 或自定义因子
        ↓
缺失处理、MAD 去极值、中性化、截面标准化、训练期因子筛选
        ↓
LightGBM / DoubleEnsemble 预测未来 5 日收益
        ↓
行业内分数排名
        ↓
样本外 Rank IC、ICIR、分组收益、交易成本与市场状态评价
        ↓
模型准入门
        ↓
TradingAgents 验真 → PPO 仓位微调 → 确定性风控 → 纸面订单
```

动态股票池、月末样本和未来收益标签属于**研究样本构建**；LightGBM 与 DoubleEnsemble 属于**模型训练与预测**；TradingAgents、PPO 和风控位于模型输出之后。各环节职责保持分离。

## 4. 如何在 Web 页面使用

### 4.1 打开页面

1. 确认服务已经启动。
2. 浏览器打开 `http://127.0.0.1:8080/`。
3. 进入“组合研究”页面。
4. 如果看不到新增选项，执行一次强制刷新。

### 4.2 推荐的沪深 300 测试参数

| 页面选项 | 推荐值 |
|---|---|
| 资产类型 | 股票 |
| 股票池 | 沪深 300 |
| 候选池大小 | 3 |
| 开始日期 | 建议至少向前 5 年，条件允许时使用 8 年 |
| 结束日期 | 留空，自动使用当前日期 |
| 预测收益周期 | 未来 5 日 |
| 调仓频率 | 每月 |
| 历史动态流动性股票池 | 勾选 |
| 动态股票数量 | 100 |
| 流动性回看窗口 | 20 日 |
| 最少历史交易日 | 250 日 |
| 行业内排名 | 勾选 |
| 因子 IC 诊断 | 勾选 |
| 多随机种子 | 3 或以上 |

**页面默认资产类型是 ETF。切换到“股票”后，请再次确认“行业内排名”已经勾选。** 非股票资产会自动禁用该选项。

选择沪深 300 等指数股票池后，“代码（逗号分隔）”输入框不会作为主要股票池来源，不需要手工填写 300 个代码。

### 4.3 因子输入方式

- 因子框留空：使用 Alpha158 默认因子。
- 每行输入一个表达式：只使用指定的自定义因子。
- 为保证不同实验可复现，不要在比较两次结果时随意更换因子列表、日期或成本参数。

### 4.4 开始运行

点击“运行组合研究流水线”。沪深 300 需要拉取并处理较多数据，运行可能需要数分钟。请等待结果区出现完整报告，不要连续重复点击。

## 5. 如何理解输出结果

### 5.1 面板与有效样本

```text
面板：200833 行 × 300 只
动态口径：回看20日 · 最少历史250日 · 有效样本2200
```

- “面板”是下载并整理后的原始股票日线规模。
- “有效样本”是经过历史长度、动态流动性 Top N 和月末截面过滤后，真正进入模型的股票日期样本。
- 有效样本远少于原始面板是正常现象，不代表数据丢失。

### 5.2 Rank IC 与 ICIR

- **Rank IC**：模型排名和未来收益排名之间的相关性。大于 0 表示方向正确，小于 0 表示排序方向可能反了。
- **ICIR**：Rank IC 均值相对于波动的稳定程度。越高通常代表越稳定，但必须结合样本数量判断。
- LightGBM 与 DoubleEnsemble 分开报告，便于观察集成模型是否真的改善稳定性。

### 5.3 样本外截面

```text
样本外截面：3 个
⚠ 样本外截面少于12个，准入结果仅供初步研究，不应进入实盘
```

月度调仓后，一个截面通常对应一个月。只有 3 个样本外月份时，即使 Rank IC 很高，也不能认为模型稳定。建议延长历史区间，并进行滚动训练，使样本外月份至少达到 24 至 36 个。

### 5.4 候选池、验真与订单

- **候选池**：模型评分靠前的股票，不等于买入建议。
- **pass**：当前证据检查未发现硬性风险。
- **observe**：存在需要观察的风险，默认不进入目标仓位。
- **PPO 调整因子**：只在严格范围内微调仓位，不负责推翻模型方向。
- **风控订单**：通过确定性风控后的拟议订单。
- **纸面提交 accepted**：订单进入仿真账户，不代表真实券商已成交。
- **真实执行=false、paper-only=true**：系统仍处于研究和纸面仿真状态。

## 7. 日常使用建议

1. 固定股票池、因子和成本假设，建立基准实验。
2. 每次只改变一个变量，例如只把标签从 5 日改为 10 日。
3. 优先查看样本外截面数量、Rank IC 稳定性、分组收益单调性和扣费后收益。
4. 使用多随机种子检查结果是否依赖偶然初始化。
5. 使用滚动训练检查模型在不同时段是否持续有效。
6. 模型未通过准入门时接受“保持现金”，不要为了生成候选股票而降低标准。
7. 通过研究门槛后先进行长期纸面仿真，再讨论人工实盘审核。

## 8. 当前限制与下一步

1. 当前行业分类来自静态 `stock_basic.industry`，历史回填仍可能产生时点偏差。
2. 本轮未加入基本面质量过滤。必须先按公告日期重建历史可见财务数据，否则会产生前视偏差。
3. 页面会提示样本外截面不足，但当前模型准入门还没有把“最少样本外截面数”设为硬性拒绝条件。
4. 动态股票池按已有行情中的流动性排序，仍需继续核验历史指数成分的时点准确性。
5. 回测和纸面仿真结果不代表未来收益，也不构成投资建议。
6. 系统真实交易开关保持关闭，AI 无权绕过风控或直接下单。

建议下一阶段优先完成：

- 将样本外月度截面不少于 24 或 36 个纳入模型硬性准入；
- 增加 walk-forward 汇总报告；
- 引入按公告日对齐的 point-in-time 基本面数据；
- 对行业分类和历史指数成分增加版本与时点审计；
- 使用更长历史区间重新测试动态 Top 100。
