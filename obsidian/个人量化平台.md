# 个人量化交易平台

## 项目定位

面向中国大陆个人开发者的多市场量化平台，目前是 paper-only MVP：A 股 ETF（QMT paper）、国内期货（CTP paper）、外汇（MT5 paper），以及 Python 回测、行情研究、风控、组合、审计和 AI 研究助手。

## 启动

```bash
cd /Users/apple/personal-quant-platform
PYTHONPATH=src python3 -m unittest discover -s tests -q
PYTHONPATH=src python3 -m quant_platform check
PYTHONPATH=src python3 -m quant_platform serve --host 127.0.0.1 --port 8080
```

浏览器打开：`http://127.0.0.1:8080/`

## DeepSeek 配置

```yaml
model:
  enabled: true
  provider: deepseek
  base_url: https://api.deepseek.com
  name: deepseek-flash
  api_key_env: AI_API_KEY
  temperature: 0.2
  max_tokens: 2000
```

```bash
export AI_API_KEY="你的 DeepSeek API Key"
```

AI 研究助手显示“DeepSeek 研究完成”才表示实际调用外部模型；“编排完成”表示本地规则模式。模型禁止下单、撤单、修改风控和索取账户密钥。

## 排错

- `Unexpected end of JSON input`：服务停止、旧服务未重启或接口返回空响应。
- 无法重启：旧 Python 进程占用 8080；在旧终端按 `Ctrl+C` 后再启动。
- 页面显示旧内容：macOS 使用 `⌘ + Shift + R` 强制刷新。
- 项目目前没有持久化 DeepSeek 调用日志，无法事后确认历史请求。

## 安全边界

- `live_trading_enabled=false`
- `ai_execution_tools_enabled=false`
- `execution_enabled=false`
- 三个市场适配器全部为 paper 模式
- AI 只能研究和分析，不能下单或撤单
